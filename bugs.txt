72. Opening the Publishers view for the first time froze the app for over 2 minutes (logs show ~12,000 sequential DB queries between 13:17:35 and 13:19:33). PublisherTreeWidget.calculate_recursive_album_count() in publisher_tree.py issues one AlbumPublisher query and one child-Publisher query per publisher, then recurses into every child - so descendant subtrees get requeried again and again as each ancestor computes its own total, and it all runs on the main thread instead of a background worker like the duplicate scan does. With ~2,187 publishers this is what caused the freeze. Should compute album counts with a single grouped query (like genre_view.py already does for genres) and build the recursive totals bottom-up in Python.

73. menu_bar.py's _icon_exists() always returns False, so the General Settings menu item never gets its icon. asset_paths.icon() returns a QIcon, not a path string, so os.path.exists(path) throws "path should be string, bytes, os.PathLike or integer, not QIcon" every time (caught and logged as debug, silently swallowed). Fix by checking the underlying file path before wrapping it in QIcon.
